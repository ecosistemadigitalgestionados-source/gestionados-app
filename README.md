# 🏢 Gestionados – Administración y Limpieza de Copropiedades

> Plataforma web corporativa full-stack desarrollada a medida para **Gestionados**, especializada en servicios de administración y limpieza de alto nivel para inmuebles y copropiedades. Diseñada para ofrecer una experiencia visual impecable, carga ultra rápida y gestión de contactos en tiempo real.

## 🚀 Funcionalidades Principales

* ⚡ **Galería Multimedia Ultra Optimizada:** Integración de imágenes procesadas en formato **WebP** con carga diferida (`loading="lazy"`) y decodificación asíncrona (`decoding="async"`), logrando una navegación fluida y ligera sin sacrificar nitidez visual.
* 📩 **Formulario de Contacto Interactivos:** Componentes responsivos de captura de requerimientos para solicitudes de cotización de administración y servicios de limpieza.
* 🔒 **Backend de Gestión:** API REST para el procesamiento seguro de solicitudes, almacenamiento de mensajes y control administrativo.
* 📱 **Diseño Corporativo & Responsive:** Interfaz moderna, adaptada a cualquier tamaño de pantalla (Mobile-First) con componentes dinámicos en Vue.js.

---

## 🛠️ Tecnologías Utilizadas

### 💻 Frontend
* **Vue.js (Composition API):** Arquitectura modular para una SPA rápida y fluida.
* **Vite:** Entorno de desarrollo y empaquetador de alto rendimiento.
* **Tailwind CSS:** Diseño utilitario y adaptativo para la interfaz corporativa.

### ⚙️ Backend & Base de Datos
* **Node.js & Express:** Servidor y API REST para el manejo de formularios y servicios.
* **PostgreSQL:** Base de datos relacional para el registro de contactos y administración.
* **Render:** Despliegue en producción del servicio web.
